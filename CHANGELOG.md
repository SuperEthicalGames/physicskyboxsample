# Changelog

All notable changes to this package will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows Semantic Versioning where applicable.

## [0.0.1] - 2026-08-27

### Added

- Initial release of Physic Skybox Sample.
- Astronomical time system.
- Real-time, manual, UTC, and simulated time modes.
- Solar position and orientation calculations.
- Lunar position and orientation calculations.
- Solar and lunar altitude and azimuth calculations.
- Lunar phase and illumination calculations.
- Atmospheric refraction correction.
- Lunar topocentric correction.
- Day and night cycle management.
- Dynamic Sun and Moon lighting.
- Dynamic ambient lighting.
- Dynamic fog.
- URP post-processing integration.
- Astronomical skybox rendering.
- Stars and constellation support.
- Cloud rendering.
- Solar and lunar eclipse effects.
- Shader integration.
- Demonstration scene.
- Unity tests.
